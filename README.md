# MECH CONNECT AI

> **"Your Vehicle. Our AI. Help When You Need It."**

An AI-powered vehicle assistance and emergency mechanic-connect platform built with React, Tailwind CSS, React Router, Lucide icons, and Leaflet interactive maps.

---

## 🌟 Key Features

### 1. AI Vehicle Diagnostic Center
- **Acoustic Engine Noise AI**: Microphone recording simulation & sample audio spectrum visualizer (Rod Knock, Belt Squeal, Brake Grind, Wheel Bearing Drone).
- **Dashboard Warning Light Optical AI**: Optical OCR detection for Check Engine, Oil Pressure, Battery, Overheating, Brakes, ABS, TPMS.
- **OBD-II DTC Code Database**: Search 5,000+ diagnostic trouble codes with plain-English causes and repair estimates.
- **Dynamic Diagnostic Reports**: Severity rating, DIY safety guidelines, and 1-click specialist booking.

### 2. Emergency Roadside SOS & Live GPS Dispatch
- High-precision GPS auto-location detection.
- Upfront fixed pricing for Jumpstarts ($49), Flat Tyres ($55), Flatbed Towing ($89), Fuel Delivery ($45), and Lockouts ($65).
- **Live GPS Tracking Map**: Real-time simulated movement of assigned mobile mechanic van towards stranded vehicle with live ETA countdown.
- **In-App Encrypted Chat & Direct Calling** with assigned rescue technician.

### 3. Mechanics & Garages Directory
- Interactive Leaflet map with custom workshop markers and filters (EV/Hybrid, 24/7, Mobile Vans, German Specialists).
- Detailed mechanic credentials, ASE master certifications, and customer ratings.
- Step-by-step appointment booking calendar with instant confirmation.

### 4. Digital Garage & Vehicle Health Passports
- Multi-vehicle garage manager with VIN decoder.
- Real-time component wear tracking (Brake pad life %, Battery health %, Tyre tread depth %).
- AI predictive maintenance schedule.
- Service history log with digital invoice receipt previews & PDF download.

### 5. Mechanic Partner Portal
- Status switch: *Online for SOS Dispatch* vs *Offline*.
- Incoming priority emergency radar dispatch alerts.
- Turn-by-turn route navigation HUD to customer location.
- Real-time daily earnings tracker.

### 6. Transparent Repair Cost Estimator
- Instant calculation of OEM parts vs certified labor rates vs typical dealership markups.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 18, JavaScript (ES6+), HTML5, Modern Responsive CSS
- **Styling**: Tailwind CSS v4, Glassmorphism, CSS Variables
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Interactive Maps**: Leaflet & React-Leaflet
- **Animations**: CSS Keyframe glow/radar pulses, Canvas Confetti
- **State & Service Layer**: React Context API (`AuthContext`, `ToastContext`), Modular service interfaces ready for Firebase Authentication, Google Maps API, and AI Vision/Audio APIs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/hb452431-prog/Mech-Connection-AI.git

# Navigate into directory
cd Mech-Connection-AI

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
npm run build
```
